About Fruit Island Turkiye

Fruit Island Turkiye is my original digital drama channel. I create my own fruit and vegetable characters, stories, animated scenes, and serialized episodes for social media.

The project combines character design, animation, storytelling, and drama inside one original fictional universe.

About This Collection

This collection features Maydanaz, Piraz, Cevdet, Narsu, Narhun, Kirnaz, Ozum, and Yesar. I created these characters as part of the Fruit Island Turkiye universe.

I selected this collection because it represents both my visual design work and the storytelling behind my channel.

Design Style

This website uses a three-color palette and two complementary fonts to create a consistent visual identity inspired by the natural and dramatic themes of Fruit Island Turkiye.
